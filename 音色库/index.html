读这一页就够

一个角色 = 一个文件夹，名字写对了程序才认

两个引擎的规矩不一样：GPT-SoVITS 靠目录名扫描，AivisSpeech 靠 uuid 文件名。 下面的工具会自动按规矩装好，但知道规矩能救你无数次。

1

先选一条路线

要做中文配音，或一句里中英日混着说 → 走 GPT-SoVITS。
只要纯日语、要换情绪（あまあま / からかい 等） → 走 AivisSpeech。
两条都装不冲突，端口分开，可以同时开。

GPT-SoVITS · 4000+ 角色 AivisSpeech · 76 声线
2

去哪里找

GPT-SoVITS：ModelScope 上的 AI-Hobbyist 合集，按「游戏 / 语言 / 角色.zip」组织， 共 849GB、8 个游戏目录（原神 / 妮姬 / 崩坏三 / 明日方舟 / 星穹铁道 / 绝区零 / 蔚蓝档案 / 鸣潮）。 语言只有 中文 日语 韩语 三种。

AivisSpeech：AivisHub 官方 API，共 76 个公开声线，分 3 页。

本页左侧两个标签就是这两处的浏览器，已经帮你把 CORS 和中文编码都处理了。 每张卡片右下角的「来源 ↗」会开到官方页面，能看作者、授权条款和试听——装之前建议点开看一眼授权。

3

放哪里（这步最容易错）

GPT-SoVITS D:\TTS\GSVI\GPT-SoVITS-1007-cu124\models\v4\<游戏>-<语言>-<角色>\
AivisSpeech %APPDATA%\AivisSpeech-Engine\Models\<uuid>.aivmx
目录名公式
蔚蓝档案-中文-爱丽丝✓ 能扫到
爱丽丝✗ 少两段，扫不到
BlueArchive-zh-Alice✗ 语言必须写中日韩

文件夹里必须有：*.ckpt（GPT 权重）+ *.pth（SoVITS 权重）+ reference_audios\<语言>\emotions\【情感】文本.wav。

4

确认它被扫到了

curl http://127.0.0.1:8000/models/v4

看到你的新目录名就成功了。本机实测 GSVI 每次请求都重新扫描， 装完直接刷新浏览器即可，不用重启；个别老版本才需要关掉黑窗口重开。

AivisSpeech 不一样：.aivmx 只在引擎启动时加载，必须重启引擎， 之后 /speakers 才会列出来。

中文名会变乱码

音色 zip 里的文件名是 GBK 编码。用资源管理器右键解压没问题，用 Python 解要加 metadata_encoding='gbk'，否则解出来一堆问号目录名。

授权看 license_type，不看模型名

ACML 1.0 可商用；ACML-NC / CC-BY-NC 只能自用二创。 本机的「蔚蓝档案-爱丽丝」是 CC-BY-NC，不能接商单。

语言参数只认这几个词

中文 英语 日语 粤语 韩语 中英混合 日英混合 粤英混合 韩英混合 多语种混合。 写「日文」直接报参数错误。
